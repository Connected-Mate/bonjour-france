Politique de confidentialité

Dernière mise à jour : 30 septembre 2026

L’essentiel en quelques lignes

— Aucun cookie, aucun traceur, aucune mesure d’audience, aucune publicité, aucun compte. Le site ne vous identifie pas et ne vous suit pas.

— L’éditeur ne conserve aucune donnée : pas de base de données, pas de journaux, pas d’historique de vos questions.

— Quand vous posez une question à l’assistant et que vous cliquez sur « Continuer », votre question et le contexte utile sont transmis par votre navigateur au service Puter (Puter Technologies Inc., Canada), qui fait générer la réponse par un modèle de Mistral AI, entreprise française. Puter vous ouvre pour cela un accès gratuit, temporaire ou lié à votre compte, régi par sa politique de confidentialité. Rien n’est envoyé tant que vous n’avez pas cliqué, et l’éditeur ne reçoit rien.

— Si vous refusez, l’assistant affiche une fiche vérifiée, sans rien envoyer, et vous propose un lien vers le service de Mistral (chat.mistral.ai).

— Le site est hébergé par GitHub (États-Unis), qui enregistre l’adresse IP des visiteurs pour des raisons de sécurité, comme tout hébergeur.

Le reste de cette page détaille ces points, conformément aux articles 12 à 14 du règlement général sur la protection des données (RGPD).

Responsable du traitement

Le responsable des traitements mis en œuvre par le site (conception de l’assistant et détermination de ce que votre navigateur transmet, compteur d’étoiles, stockage local) est Alexandre Cormeraie, particulier, éditeur de « Bonjour, France ». Contact : LinkedIn (échange privé) ou GitHub (public, n’y écrivez pas de données personnelles). Il n’y a pas de délégué à la protection des données, cette désignation n’étant pas obligatoire pour un particulier.

Les prestataires techniques traitent certaines données pour leur propre compte, selon leurs politiques respectives : GitHub (hébergement), Puter (accès à Mistral, compte et session) et Mistral AI (génération des réponses, en tant que fournisseur de Puter). L’éditeur n’a conclu aucun contrat avec Puter ni avec Mistral AI dans ce mode : vous contractez directement avec Puter en acceptant son accès, et Puter est responsable de ses propres traitements. Cloudflare n’intervient, comme sous-traitant de l’éditeur, que si le mode relais décrit à la section 2 est activé. Les détails figurent ci-dessous.

Ce qui ne se passe pas sur ce site

Pour lever tout doute :

— aucun cookie n’est déposé par le site lui-même ; le service Puter, si vous choisissez de l’activer, enregistre son propre jeton de session dans le stockage local de votre navigateur et peut, dans sa propre fenêtre, utiliser des cookies selon sa politique (section 2) ;

— aucun outil de mesure d’audience (statistiques de visite) n’est utilisé ;

— aucune régie publicitaire, aucun bouton de partage traçant, aucune police ou script chargé depuis un service de suivi ;

— aucune inscription, aucun compte, aucune adresse e-mail demandée par « Bonjour, France » ; seul le service Puter, à votre demande, vous ouvre un accès (temporaire ou lié à votre compte Puter) ;

— aucune donnée n’est vendue, louée ni transmise à des fins commerciales.

1. Consultation du site (hébergement GitHub Pages)

Le site est un ensemble de pages statiques servies par GitHub Pages. Lorsque vous le consultez, votre navigateur envoie à GitHub les informations techniques habituelles de toute connexion (adresse IP, pages demandées, type de navigateur, date et heure).

— Données : adresse IP, journaux techniques de connexion.

— Qui traite : GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, États-Unis, pour son propre compte. GitHub indique que « l’adresse IP du visiteur est enregistrée et conservée à des fins de sécurité, que le visiteur soit connecté à GitHub ou non ». L’éditeur n’a pas accès à ces journaux.

— Finalité et base légale : sécurité et bon fonctionnement de l’hébergement — intérêt légitime de GitHub (art. 6, § 1, f RGPD).

— Durée : définie par GitHub selon sa déclaration de confidentialité.

— Transfert hors UE : États-Unis ; GitHub déclare être certifié au titre du cadre de protection des données UE–États-Unis (voir la section « Transferts »).

2. Assistant de conversation (Puter et Mistral AI)

L’assistant fonctionne selon trois modes. Par défaut, il utilise le service Puter ; le mode relais n’est proposé qu’à titre alternatif, si l’éditeur l’active ; dans tous les cas, vous pouvez refuser tout envoi et rester en mode fiche seule.

Mode fiche seule (par défaut si vous refusez, ou si Puter est indisponible). L’assistant recherche dans votre navigateur la fiche vérifiée qui correspond à votre question et l’affiche. Rien n’est transmis à un serveur. Un lien « Demander à Mistral » ouvre, si vous le souhaitez, le service chat.mistral.ai avec votre question préremplie : à partir de là, c’est Mistral AI qui traite vos données, selon ses propres conditions et sa politique de confidentialité, sans intervention de « Bonjour, France ».

Mode Puter (par défaut, après votre accord). Quand vous posez une question, l’assistant affiche une explication et attend que vous cliquiez sur « Continuer ». Votre navigateur charge alors la bibliothèque Puter.js depuis js.puter.com et une fenêtre du service Puter s’ouvre pour vous connecter à votre compte Puter ou, si vous n’en avez pas, vous créer automatiquement un accès temporaire gratuit. Une fois cet accès ouvert, votre navigateur transmet directement à Puter, qui fait générer la réponse par un modèle de Mistral AI (mistral-medium-latest ou, à défaut, un autre modèle Mistral) et la renvoie dans le chat au fil de sa rédaction :

— votre question ;

— les derniers messages de la conversation en cours (au maximum 10), pour garder le fil ;

— le texte de la fiche vérifiée correspondante ;

— si vous avez joint un document PDF : un extrait de son texte. Le PDF est lu dans votre navigateur ; le fichier lui-même n’est jamais envoyé, seul le texte extrait l’est.

Puter reçoit en outre, pour son propre fonctionnement, votre adresse IP et les informations techniques de votre navigateur, et vous attribue un compte (temporaire ou durable). Chaque visiteur utilise son propre accès gratuit : Puter fixe seul les limites de cet accès (modèle dit « l’utilisateur paie », sans frais dans la limite de l’allocation gratuite, selon Puter). L’éditeur ne reçoit rien : ni votre question, ni la réponse, ni votre identité Puter, ni votre adresse IP.

Ces contenus peuvent comporter des données personnelles si vous en écrivez dans votre question ou dans le document joint. Nous vous recommandons de ne pas en indiquer, et surtout aucune donnée sensible (santé, numéro de sécurité sociale, données bancaires). Si vous choisissez néanmoins d’en transmettre, ce traitement repose sur votre démarche volontaire et explicite.

— Finalité : produire la réponse que vous demandez.

— Base légale : votre consentement, manifesté par le clic sur « Continuer » après l’explication affichée (art. 6, § 1, a RGPD) ; vous pouvez le retirer à tout moment en refusant l’envoi suivant, en fermant la fenêtre Puter ou en vous déconnectant de Puter, sans effet sur les envois déjà effectués. Pour d’éventuelles données sensibles que vous décideriez d’inclure, votre consentement explicite manifesté par cet envoi (art. 9, § 2, a).

— Rôles : l’éditeur, qui a conçu le site, est responsable de la transmission déclenchée par votre navigateur (quelles données, vers qui). Puter Technologies Inc., Vancouver (Colombie-Britannique, Canada), traite ensuite pour son propre compte, en tant que responsable de son service : ouverture et gestion de votre accès, acheminement de la demande vers Mistral, journaux techniques et facturation éventuelle de l’allocation dépassée. Voir sa politique de confidentialité et ses conditions d’utilisation. Selon Puter, sa politique ne s’applique pas au contenu de vos « données utilisateur », qu’il traite pour vous rendre le service demandé.

— Modèle de langage (Mistral AI) : Mistral AI SAS, 15 rue des Halles, 75001 Paris, France, fournisseur de Puter dans ce mode (l’éditeur n’a aucun contrat avec Mistral AI). La conservation de vos échanges par Mistral dépend des conditions convenues entre Puter et Mistral, que l’éditeur ne connaît pas ; à titre indicatif, Mistral indique conserver les entrées et sorties de son interface de programmation le temps de produire la réponse, puis 30 jours glissants à des fins de surveillance des abus, sans les utiliser pour entraîner ses modèles dans ce cadre. Voir sa politique de confidentialité.

— Durée côté éditeur : aucune conservation. La conversation n’existe que dans la mémoire de votre navigateur et disparaît quand vous quittez ou rechargez la page. Le jeton de session déposé par Puter dans le stockage local de votre navigateur subsiste jusqu’à ce que vous l’effaciez (section 5).

— Transfert hors UE : Puter est établie au Canada ; ses prestataires d’hébergement peuvent se situer aux États-Unis (voir « Transferts »). Mistral AI est établie en France.

Mode relais (alternative, uniquement si l’éditeur l’active). Dans ce mode, signalé dans l’explication affichée avant tout envoi, aucune fenêtre Puter ne s’ouvre : votre navigateur transmet les mêmes éléments (question, 10 derniers messages au plus, fiche, extrait de PDF) à un relais géré par l’éditeur, exécuté sur Cloudflare Workers, puis à l’interface de programmation de Mistral AI.

— Base légale : l’intérêt légitime de l’éditeur à répondre à la question que vous lui posez (art. 6, § 1, f RGPD), traitement déclenché uniquement par votre action et limité au strict nécessaire ; consentement explicite (art. 9, § 2, a) pour d’éventuelles données sensibles que vous incluriez.

— Relais (Cloudflare Workers) : Cloudflare, Inc., 101 Townsend Street, San Francisco, CA 94107, États-Unis, sous-traitant de l’éditeur. Le relais ne conserve rien : aucune base de données, aucun journal du contenu des questions ou des réponses. Cloudflare traite l’adresse IP pour acheminer la requête et appliquer une limite de 10 questions par minute et par adresse IP (protection contre les abus), ainsi que ses journaux techniques selon son accord de traitement des données.

— Modèle de langage (Mistral AI) : Mistral AI SAS, sous-traitant de l’éditeur au titre de son addendum de traitement des données. Modèle utilisé : mistral-small-latest. Conservation : le temps de produire la réponse, puis 30 jours glissants pour la surveillance des abus, sans entraînement des modèles (selon Mistral). Voir la liste de ses sous-traitants ultérieurs.

— Transfert hors UE : le relais Cloudflare peut faire transiter les requêtes par des infrastructures situées hors de l’Union européenne (voir « Transferts »).

3. Saisie vocale

Le bouton micro utilise la reconnaissance vocale intégrée à votre navigateur (interface Web Speech). Selon le navigateur, l’audio peut être envoyé aux serveurs de son éditeur (par exemple Google pour Chrome, Apple pour Safari) pour être transcrit ; « Bonjour, France » ne reçoit que le texte final et n’enregistre aucun son. Ce traitement relève de la politique de confidentialité de votre navigateur. Le micro ne s’active qu’après votre autorisation et vous pouvez toujours taper votre question à la place.

4. Compteur d’étoiles GitHub

Le site affiche le nombre d’« étoiles » de son dépôt. Pour cela, votre navigateur interroge directement l’interface publique de GitHub (api.github.com), qui voit donc votre adresse IP, comme pour la consultation du site (section 1). Aucun identifiant ne vous est associé. Le résultat est mémorisé dans le stockage local de votre navigateur pendant 10 minutes pour éviter des appels répétés. Base légale : intérêt légitime de l’éditeur à afficher une information publique sans surcharger GitHub (art. 6, § 1, f RGPD). Si l’appel échoue (hors ligne, limite atteinte), le site fonctionne normalement sans le compteur.

5. Stockage local du navigateur

Le site utilise le stockage local (« localStorage ») de votre navigateur, jamais de cookies, pour :

— mémoriser le compteur d’étoiles pendant 10 minutes ;

— mémoriser, le cas échéant, des préférences d’affichage (par exemple le thème choisi).

— conserver, si vous avez activé l’assistant, le jeton de session du service Puter. Ce jeton est déposé et lu par Puter, jamais par l’éditeur ; il n’existe qu’après votre clic sur « Continuer » et vous permet de ne pas rouvrir la fenêtre Puter à chaque question.

Les deux premières informations restent sur votre appareil, ne sont jamais envoyées à l’éditeur ni à un tiers, ne contiennent aucun identifiant et servent uniquement au fonctionnement du service que vous demandez. Le jeton Puter, lui, identifie votre accès auprès de Puter et est transmis à Puter à chaque question ; il relève de la politique de confidentialité de Puter. Conformément à l’article 82 de la loi Informatique et Libertés, ces accès sont strictement nécessaires au service que vous avez expressément demandé. Vous pouvez tout effacer à tout moment depuis les réglages de votre navigateur (données de site), ce qui vous déconnecte de Puter ; sur un appareil partagé, pensez-y. Si le stockage est indisponible ou bloqué, le site continue de fonctionner (la fenêtre Puter peut alors se rouvrir à chaque question).

Destinataires

Les seules entités susceptibles de traiter des données dans le cadre décrit ci-dessus sont : GitHub, Inc. (hébergement, interface publique) ; Puter Technologies Inc. (accès à l’assistant, compte et session, acheminement vers Mistral) ; Mistral AI SAS (modèle de langage, comme fournisseur de Puter ou, en mode relais, comme sous-traitant de l’éditeur) ; Cloudflare, Inc., uniquement si le mode relais est activé ; et, pour la saisie vocale, l’éditeur de votre navigateur. Puter indique recourir à ses propres prestataires (hébergement, sécurité, paiement) selon sa politique. L’éditeur ne transmet aucune donnée à quiconque d’autre, sauf obligation légale.

Transferts hors de l’Union européenne

Puter Technologies Inc. est établie au Canada. La Commission européenne reconnaît au Canada un niveau de protection adéquat pour les organisations soumises à la loi fédérale canadienne sur la protection des renseignements personnels (décision 2002/2/CE du 20 décembre 2001, maintenue lors du réexamen publié par la Commission le 15 janvier 2024). Puter indique toutefois recourir à des prestataires tiers pour l’hébergement de ses données, dont l’éditeur ne connaît pas la localisation ; ils peuvent se trouver aux États-Unis. Les garanties applicables à ces sous-traitants relèvent de la politique de confidentialité de Puter, que vous acceptez en ouvrant votre accès.

GitHub, Inc. et, si le mode relais est activé, Cloudflare, Inc. sont des sociétés américaines. Les données techniques traitées par ces prestataires peuvent donc être transférées vers les États-Unis. Ces transferts s’appuient sur la décision d’adéquation de la Commission européenne du 10 juillet 2023 relative au cadre de protection des données UE–États-Unis (« Data Privacy Framework »), auquel GitHub et Cloudflare déclarent avoir adhéré, et, à titre complémentaire, sur les clauses contractuelles types intégrées à leurs accords de traitement.

Pour information : la validité de cette décision d’adéquation a été confirmée par le Tribunal de l’Union européenne le 3 septembre 2025 ; un pourvoi est en cours devant la Cour de justice. En cas d’évolution, cette page sera mise à jour.

Mistral AI SAS est établie en France ; le traitement de vos questions par le modèle de langage n’implique pas de transfert par l’éditeur. Les éventuels sous-traitants ultérieurs de Mistral figurent dans son centre de confiance.

Durées de conservation

— Par l’éditeur : aucune donnée conservée.

— Puter : données de compte, de session et journaux techniques selon sa politique de confidentialité ; un accès temporaire non converti en compte reste régi par les conditions de Puter. Puter indique ne pas collecter de données personnelles contenues dans vos « données utilisateur ».

— Mistral AI : entrées et sorties conservées le temps de produire la réponse, puis 30 jours glissants pour la surveillance des abus (selon Mistral, pour son interface de programmation ; en mode Puter, sous réserve des conditions convenues entre Puter et Mistral).

— Relais Cloudflare (si activé) : aucune conservation du contenu ; compteur de limite d’usage éphémère (une minute) ; journaux techniques de Cloudflare selon sa politique.

— GitHub : journaux de connexion selon sa politique de confidentialité.

— Votre navigateur : stockage local jusqu’à effacement par vous (préférences, jeton de session Puter) ; le cache du compteur d’étoiles expire après 10 minutes.

Vos droits

Conformément aux articles 15 à 22 du RGPD, vous disposez d’un droit d’accès, de rectification, d’effacement, de limitation, d’opposition et, le cas échéant, de portabilité de vos données, ainsi que du droit de définir des directives relatives au sort de vos données après votre décès (article 85 de la loi Informatique et Libertés).

Point important : l’éditeur ne conserve aucune donnée et n’est pas en mesure de vous identifier (article 11 du RGPD). Pour la plupart des demandes, il ne pourra donc que vous confirmer cette absence de données et vous orienter vers le prestataire concerné : Puter (votre accès et vos échanges via l’assistant — vous pouvez aussi supprimer votre compte Puter depuis puter.com), Mistral AI, GitHub ou, en mode relais, Cloudflare, qui disposent chacun de leur propre procédure.

Pour exercer vos droits auprès de l’éditeur, écrivez-lui sur LinkedIn (canal privé recommandé). Une réponse vous sera apportée dans un délai d’un mois, prolongeable de deux mois si la demande est complexe, conformément à l’article 12 du RGPD.

Si vous estimez, après nous avoir contactés, que vos droits ne sont pas respectés, vous pouvez adresser une réclamation à la CNIL (Commission nationale de l’informatique et des libertés), 3 place de Fontenoy, TSA 80715, 75334 Paris Cedex 07, ou en ligne sur cnil.fr/fr/plaintes.

Sécurité

Le site est servi exclusivement en HTTPS ; les échanges avec Puter, avec Mistral AI et, le cas échéant, avec le relais sont eux aussi chiffrés en transit. Le site n’a ni serveur, ni base de données, ni journal : il n’existe chez l’éditeur aucune donnée à protéger. La bibliothèque Puter.js n’est chargée qu’après votre clic sur « Continuer », jamais avant. Le jeton de session Puter reste dans votre navigateur : sur un appareil partagé, effacez les données de site après usage. En mode relais, le relais n’accepte que les requêtes de l’assistant, limite le volume par adresse IP et ne stocke rien. Le code du site est public et peut être audité par quiconque sur GitHub.

Mineurs

Le site ne s’adresse pas spécifiquement aux mineurs et ne collecte aucune donnée permettant d’en identifier. Les recommandations ci-dessus (ne pas saisir de données personnelles dans l’assistant) valent tout particulièrement pour les plus jeunes.

Modifications

Cette politique peut évoluer, notamment en cas de changement du mode de fonctionnement de l’assistant (Puter, relais ou fiches seules), d’ajout d’une fonctionnalité ou de changement de prestataire. La date de mise à jour figure en tête de page et l’historique des modifications est consultable dans le dépôt GitHub du site.

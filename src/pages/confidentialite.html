Confidentialité

Pas de compte, pas de publicité, pas de pisteur. Vos questions restent sur votre appareil.

Ce que nous ne faisons pas

  • Aucune donnée personnelle collectée, aucun cookie, aucune mesure d’audience.
  • Vos questions ne sont envoyées à aucun serveur d’IA : Mistral tourne dans votre navigateur.
  • La conversation n’est pas enregistrée : elle disparaît quand vous fermez ou rechargez la page.
  • Les PDF joints sont lus sur votre appareil ; seul le texte est gardé, le temps de la question.

Les services contactés par votre navigateur

Comme tout site, votre navigateur télécharge des ressources auprès de tiers, qui voient alors votre adresse IP :

  • GitHub Pages (hébergement du site) et l’API GitHub (compteur de votes).
  • Google Fonts (polices EB Garamond et Hanken Grotesk).
  • jsDelivr et cdnjs (bibliothèques WebLLM et pdf.js), Hugging Face et GitHub (fichiers du modèle Mistral).
  • Les API publiques listées dans Comment ça marche, uniquement quand vous utilisez les outils correspondants. Seul le texte utile leur est envoyé (un nom de commune, une adresse…).

Dictée vocale : le bouton micro utilise la reconnaissance vocale de votre navigateur. Dans Chrome et Edge, le son est transcrit par les serveurs de Google ou Microsoft. Si vous préférez, tapez simplement votre question.

Vos droits

Comme nous ne collectons aucune donnée personnelle, il n’y a rien à consulter ni à supprimer chez nous. Pour toute question : ouvrir un ticket sur GitHub.
